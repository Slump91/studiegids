# Studiegids Film- en videomaker

Web-app (PWA) van de studiegids Film- en videomaker van Noorderpoort, gehost via GitHub Pages.

## Installeren als app
- **iPhone/iPad:** open de site in Safari → deelknop → *Zet op beginscherm*.
- **Android:** open de site in Chrome → menu ⋮ → *App installeren* of *Toevoegen aan startscherm*.

## Bestanden
- `index.html`: de hele studiegids
- `manifest.webmanifest`: naam, kleuren en icoon van de app
- `sw.js`: zorgt dat de app ook zonder internet opent (laatst bekeken versie)
- `icons/`: app-iconen
